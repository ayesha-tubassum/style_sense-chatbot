About the project

A fashion assistant that actually understands dress codes

StyleSense AI began as a Gradio chatbot built on Hugging Face Transformers. It was designed with one narrow, deliberate mission: to give practical fashion and styling guidance — never to wander into unrelated small talk.

This website is the production face of that assistant. The same specialist personality now lives inside a fast, elegant interface you can use on any device, with optional connection to a hosted large-language-model endpoint.

  • ✓ Single-purpose fashion system prompt
  • ✓ Occasion, colour, fabric & body-shape aware
  • ✓ Budget-conscious, culturally respectful advice
  • ✓ Works offline — no API key required
